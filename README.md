\# 🇯🇵 KaiwaBuddy



\### Your Local AI Japanese Conversation Partner



KaiwaBuddy is a beginner-friendly Japanese learning assistant that helps learners practice Japanese conversation, understand grammar, correct common mistakes, and build vocabulary.



It is designed around \*\*Minna no Nihongo N5 Lesson 1\*\* concepts and uses a hybrid approach combining deterministic Japanese learning rules with a local open-weight AI model.



\## ✨ Features



\- 🇬🇧 Japanese → English meaning

\- 🧩 Grammar explanations

\- ✏️ Common mistake correction

\- 💬 Guided Japanese conversation

\- 🎯 Practice Mode

\- 📚 Vocabulary Mode

\- 🧠 Conversation memory

\- 🔒 Local AI inference

\- 🤖 Gemma 3 1B through Ollama



\## 🛠️ Tech Stack



\- Python

\- Streamlit

\- Ollama

\- Gemma 3 1B
